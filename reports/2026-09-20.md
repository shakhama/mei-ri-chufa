### 本次修复的根因（重要）

git push 在非交互环境下永久挂起、且不报错。排查结论：

- 不是网络问题：api.github.com 直连与代理均 HTTP 200，git ls-remote 秒回。
- 不是凭据失效：Windows 凭据管理器里的 git:https://github.com 凭据有效。
- 真正原因：仓库继承了全局 credential.helper=helper-selector，
  该选择器在非交互会话里取不到凭据时会挂起等终端输入 → push 卡死不返回。
- 解法：先用 `-c credential.helper=` 清空 helper 列表（空值即清空），
  再用 `-c credential.helper=manager` 指定 Windows 凭据管理器。顺序不可颠倒。

已同步改进 daily_run.py：
1. push 统一走上面这条凭据修正命令；
2. push 单路加 70s 超时，超时即换代理重试，不再无限挂起；
3. push 失败时把「直连 / 代理」两路的错误都记进报告，不再静默失败。

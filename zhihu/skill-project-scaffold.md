# skill 实战：一键生成项目目录与交付清单

这是最适合作为第一个 skill 的场景：规则明确、收益立即可感知。

## 明确输入与输出

把边界写清楚，skill 就成功了一半。

- 输入：项目名、类型、交付阶段
- 输出：标准目录树与清单文件
- 约定：命名规则与必需子目录

## 实现思路

不需要复杂技术，脚本加模板即可完成。

- 用模板文件定义目录结构
- 用脚本替换变量并生成
- 生成后自动检查缺失项

## 加上校验才敢用

没有校验的自动化，出错时更难发现。

- 检查关键目录是否存在
- 输出生成结果汇总供人工确认
- 重复执行时避免覆盖已有内容

## 常见问题

**这套思路能用在哪？**

凡是每次开工都要重复搭建的东西：目录、模板、命名、清单，都适合用同样的方法做成 skill。

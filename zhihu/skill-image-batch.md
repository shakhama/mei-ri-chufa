# skill 实战：图片批量重命名、压缩与归档

设计项目里图片处理重复度极高，是自动化的高收益区。

## 先拆分环节

把一件杂事拆成明确步骤，才能逐个自动化。

- 重命名：统一项目与序号规则
- 压缩：按用途输出不同规格
- 归档：按目录结构和用途分发

## 设计好命名规则

命名规则是这个 skill 的核心资产。

- 包含项目、空间、视角等关键信息
- 排序字段保证自然排序正确
- 避免重名导致的覆盖

## 安全永远是第一位

批量操作一旦出错影响面很大。

- 先复制到临时目录再处理
- 支持试运行模式只输出计划
- 保留原始文件直至确认无误

## 常见问题

**不会写复杂代码能做吗？**

可以。这类 skill 通常由现成的图片处理工具加一层脚本组合而成，重点在流程设计。

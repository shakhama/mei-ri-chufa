# 为设计垂直领域开发 skill：把重复劳动一次性自动化

设计师最贵的成本是重复劳动。把高频、标准化的环节做成 skill，一次投入长期复用。

## 什么值得做成 skill

不是所有事都值得自动化，用这三条筛一遍。

- 高频：一周做三次以上的动作
- 有明确输入输出：规则清晰可描述
- 易出错：人工做容易漏项的步骤

## 从一个最小 skill 开始

先做小、做对，再谈做大。贪大是 skill 烂尾的主因。

- 先只解决一个具体问题，不要贪大
- 把输入输出写成明确格式：文件、参数、目录
- 加校验：产出不符合预期要能立刻发现

## 设计领域的典型场景

这几个场景几乎每个设计团队都能立刻用上。

- 批量生成效果图并做多版本对比
- 自动输出材料清单与预算表
- 自动生成设计说明与交付文档
- 按项目模板初始化目录与文件

## 常见问题

**不会写代码能做吗？**

可以。很多 skill 只是把固定流程与模板固化下来，用脚本或配置即可实现，关键先把流程描述清楚。
